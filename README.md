# GPT Test Portfolio

A small static portfolio demo project created through a GitHub workflow with ChatGPT.

## What this project shows

- A clean one-page portfolio layout
- Responsive HTML and CSS
- A small JavaScript interaction
- A branch-based workflow that can be reviewed through a pull request

## Files

```text
gpt-test-portfolio/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## How to run locally

No build step is required.

Open `index.html` directly in a browser, or serve the folder with any simple static server.

Example:

```bash
python -m http.server 3000
```

Then open:

```text
http://localhost:3000
```
